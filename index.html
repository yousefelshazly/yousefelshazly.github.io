Selected work

FlyRank: ML content prioritization

ML intern, 2026. Python, pandas, scikit-learn

Problem
The existing approach was 74% precise, so 26% of the team's effort went to content that didn't need refreshing.
What I built
A refresh opportunity label, threshold logic, and a scoring model trained on a 30,000-page search dataset across 32 clients. I found label leakage in the training data and rebuilt the target using only prior-period features.
Limitation
The label is rule-based, not a measured future outcome.

Music recommendation thesis

Sequential pattern mining. Python, K-means, PrefixSpan

8/10average user rating. 14 of 15 recommendations rated above 50%

Question
Can sequential listening patterns improve music recommendation?
What I built
K-means clustering on 2,000 Spotify tracks using 18 audio features, synthetic listening sequences, and the PrefixSpan algorithm to recommend the next track.
Limitation
The sequences were synthetic. Real listening histories would be needed to prove it at scale.
